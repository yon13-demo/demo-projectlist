# Logo Folder

Letakkan file logo Weaver di sini.

Contoh penggunaan di komponen:
  <img src="/logo/logo.png" alt="Weaver" />
  <img src="/logo/logo.svg" alt="Weaver" />

Format yang disarankan:
- logo.svg       → untuk web (scalable, rekomendasi utama)
- logo.png       → alternatif raster
- logo-dark.svg  → versi untuk dark mode (opsional)
